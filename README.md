# ATM Booth Management System

## Overview
A web-based ATM Booth Management System that allows customers to securely access their bank accounts and perform essential banking operations through an interactive ATM interface.

## Features
- Customer Registration and Login
- Secure PIN Authentication
- Cash Deposit
- Cash Withdrawal
- Fast Cash Withdrawal
- Balance Enquiry
- Mini Statement
- PIN Change
- Transaction History

## Technology Stack
- **Frontend:** Angular
- **Backend:** Python Flask
- **Database:** Microsoft SQL Server
- **ORM:** Flask-SQLAlchemy
- **Authentication:** PIN-based authentication

## Future Enhancements
- Improved authentication and security
- Transaction receipt generation
- Enhanced transaction monitoring
